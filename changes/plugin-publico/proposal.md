# Plugin público

## Por quê

O orquestrador funcionava só nesta máquina, instalado a partir de uma pasta local. Publicado como plugin num repositório público, qualquer pessoa instala com um comando, e esta própria máquina passa a usar o mesmo pacote que os outros recebem.

## O que muda

- O mod e a skill change-orchestrator viram um plugin só, com README, licença MIT e marketplace "orquestrador".
- O repositório chacal88/orquestrador passa a existir, público.
- A instalação local passa a usar o marketplace "orquestrador", e a cópia pessoal da skill sai de ~/.claude/skills.
